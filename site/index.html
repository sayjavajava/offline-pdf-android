Android · on-device PDF tools

20 PDF tools that never touch the internet

Split, merge, protect, redact and convert PDFs entirely on your own phone or tablet. Your files never leave your device, because the app has no way to send them anywhere.

Most free PDF apps upload your file to a server to process it — even to merge two pages. That means contracts, IDs, and financial statements passing through someone else's machines. OffGridPDF requests no Android permissions at all: not internet, not storage, not camera. It is enforced by Android itself, and checked on every build.

Built for real use

Batch mode runs compress, watermark, rotate or page numbers across several files at once. Tool chaining takes one result straight into the next without re-saving. There is a proper two-pane layout on tablets, light and dark themes, and an option to block screenshots entirely.

Open source

The full source is on GitHub under GPL-3.0, so every claim on this page can be checked against the code that ships. There is also a browser version with the same 20 tools, and an offline OCR tool, QuietOCR.
