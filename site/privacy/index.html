Legal & privacy

Privacy Policy

Effective 4 September 2026 App version 0.1.0 and later Package com.offgridpdf.android

OffGridPDF cannot send your files, or anything else, anywhere. It has no INTERNET permission — not switched off by a setting, but never requested in the first place, so Android itself refuses any network call the app might attempt.

That is not a promise in a document; it is an install-time fact that anyone can verify. Below is the app's actual manifest permission block, unedited:

AndroidManifest.xml
<!-- No <uses-permission> for INTERNET, anywhere in this file, ever. -->
<!-- In fact: no <uses-permission> of any kind. Zero permissions requested. -->

What this app does

OffGridPDF is a local PDF editor: 20 tools — split, merge, protect, redact, convert and more — that all run on your own device, on files you choose. There is no server behind any of them.

Permissions

OffGridPDF requests no Android permissions at all — not internet, not camera, not contacts, not location, not broad storage access. When you tap "choose a file", Android's own system file picker opens; you select one file, and the app is handed a temporary, read-only reference to just that file. It never receives a listing of your storage and cannot reach anything you did not pick yourself.

Data we collect

None. There is no account to create, no sign-up, no analytics, no crash reporting, and — per the permission above — no network connection for any of that to travel over even if it existed. The developer receives nothing about you or your files, ever, because there is no channel through which it could arrive.

What stays on your device

A few small preferences are saved locally so the app remembers how you left it. None of it is ever transmitted anywhere.

Stored locally What it is for Transmitted?
Recent tools Shows your last-used tools on the dashboard Never
Theme preference Remembers your light / dark / system choice Never
Screen-capture setting The optional "block screenshots" toggle in Settings Never
Chaining cache A temporary copy of a result, only while you are part-way through "continue with another tool"; cleared by Android's normal app-cache lifecycle and on next launch Never

Your PDF files

A file you open is read into memory, processed by the tool you chose, and written back out only when you choose where to save it — through Android's own save dialog. OffGridPDF never copies a file anywhere else on your device, or off it. Close the app and nothing of that file's content persists in it.

Tools such as Protect PDF and Redact PDF exist precisely so that you can control access to a file's contents. A password you set, or content you remove, is applied entirely on-device by local code, never sent anywhere to be processed.

Third parties

None are involved. No advertising network, no analytics vendor, no cloud PDF service. The PDF and document libraries the app is built on (Apache PDFBox, Bouncy Castle and others) run entirely inside the app, offline — they make no network calls either.

This website makes no third-party requests of its own, and sets no cookies. It loads no external fonts, scripts, or analytics — deliberately, since a page explaining that nothing is collected should not be quietly handing your address to someone else.

Children's privacy

OffGridPDF does not knowingly collect information from anyone of any age, because it does not collect information from anyone. It is not directed specifically at children, and nothing about it depends on a user's age.

Changes to this policy

If this policy changes, the date at the top of this page changes with it. Because the app's source is public, you can also check any claim here directly against the code that shipped in a given version.
